# 拡大プリント

**のりしろ分割印刷**

学校の大判プリンタ（ロール紙）で、紙の幅より大きな横断幕・垂れ幕・大型ポスターを作るための Web アプリです。
この画面で文字を入れてデザインを作り、ロール紙の幅に合わせて分けて印刷します。
分けた紙には **のりしろ・切り取り線・合わせマーク** が印刷されるので、切って重ねて貼るだけでつながります。

- インストール不要。ブラウザ（Chrome / Edge / Safari）で開くだけで使えます。
- 原稿やデザインは端末の中だけで処理します。外部には送信しません。
- 特定のプリンタ専用ではありません。ロール紙の幅と印刷できない余白を入れれば、どの大判プリンタでも使えます。

## 開き方

- **ブラウザで開く**：<https://tech-edu-lab.github.io/kakudai-print/>
- **フォルダごと配る**：このリポジトリをダウンロードし、`index.html` をブラウザで開きます。
  初回はライブラリ（pdf-lib・fontkit）と画面用の文字を読み込むため、インターネット接続が必要です。

## できること

| 機能 | 内容 |
|---|---|
| この画面で作る | 仕上がりの大きさ（例：3600×900mm）を入れ、文字・画像・四角（帯・枠）・背景色を置いてデザインする。フォント5種（ゴシック・極太ゴシック・丸ゴシック・明朝・筆文字）、縦書き、縁取り、縦だけ・横だけの伸縮、20色のパレット |
| 原稿ファイルを使う | PowerPoint などで作った PDF や、PNG・JPEG の画像を読みこんで、拡大して分ける |
| 自動の分割 | 印刷できる幅（ロール紙の幅 − 余白）に収まるように、枚数と継ぎ目の位置を計算する。紙を縦長・横長のどちらで使うかも、枚数が少ないほうを選ぶ |
| 長さ方向の分割 | 1枚が「1枚の最大の長さ」（初期値 5,000mm）を超えるときは、長さの方向にも分ける（紙の番号は ①-1、①-2 …） |
| 貼り合わせの印 | のりしろ（となりの紙と同じ絵を印刷した帯）、切り取り線（マゼンタの点線）、◎の合わせマーク、紙の番号、倍率確認用の 100mm の線 |
| テスト印刷 | 紙の四辺に目盛りを印刷して、そのプリンタの「印刷できない余白」を測る |
| 保存 | デザインは自動で下書き保存。「デザインを保存」で `.json` にして、来年また使ったり同僚に渡したりできる。1枚もの（仕上がりの大きさ）の PDF も出せる |

文字はフォントの輪郭の線（ベクター）のまま PDF に入れるので、何メートルに拡大してもぼやけません。

## 使い方

1. **余白を測る（最初の1回）**　「テスト印刷用PDF」を倍率100%で印刷し、四辺の目盛りが何mmから印刷されているかを読んで「印刷できない余白」に入れる。
2. **作る**　「この画面で作る」で文字を入れるか、「原稿ファイルを使う」で PDF や画像を読みこむ。仕上がりの大きさを入れる。
3. **印刷する**　結果欄の **「プリンタに設定する用紙サイズ」**（幅×長さ。どのページも同じ大きさ）を、プリンタのドライバにユーザー定義の用紙サイズとして登録する（多くの機種では名前を付けて「保存」してから選ぶ）。「印刷用PDFを作る」で保存した PDF を Acrobat Reader で開き、用紙はロール紙、その用紙サイズを選んで **実際のサイズ（100%）** で印刷する。「フチなし」「用紙に合わせる」は使わない。
4. **重ねて貼る**　つなぎ方は2通りから選べる。
   - **切らずに重ねる（初期設定）**：紙は切らない。下になる紙に印刷されたマゼンタの細い線に、上に重ねる紙のまっすぐな端を合わせて貼る。継ぎ目にプリンタの余白ぶん（数mm）の白いすじが出るので、白地のデザイン向き。
   - **点線で切って重ねる**：マゼンタの点線のすぐ内側で白い余白を切り落としてから重ねる。白いすじは出ない。線から内側 1cm までなら、曲がっても目立たない（下の紙に同じ絵がある）。
5. **そろえる**　紙の両端にある◎の合わせマークで、長さの向きのずれを合わせる。長さの方向にも分けたときは、先に同じ番号どうし（①-1 と ①-2）をつなぐ。
6. **仕上げる**　上下の案内の部分を、灰色の点線（仕上がり線）で切り落とす。

## プリンタの設定

機種ごとの値はアプリに入れていません。次の3つを、使うプリンタに合わせて入力してください（入力した値はブラウザが覚えます）。

- **ロール紙の幅**：594mm（A1）、610mm（24インチ）、841mm（A0）、914mm（36インチ）などから選ぶか、数値で入れる
- **印刷できない余白**：テスト印刷で測った値（左右と、紙の先端・後端）
- **1枚の最大の長さ**：プリンタと PDF ソフトが扱える長さ。プリンタの上限は、ドライバのユーザー定義の用紙サイズの画面に「長さ 127.0－15000.0」のような範囲で出ている。扱いやすい長さ（例：2,000mm）にしてもよい。PDF の標準の上限は 5,080mm（200インチ）で、これを超えるページは PDF の拡張機能（UserUnit）で作る（Acrobat Reader で印刷する）

長さの方向にも分けるときは、どのページも同じ長さ（整数 mm）になるように区切るので、ドライバに登録する用紙サイズは1つで済みます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面と見た目 |
| `core.js` | 分割の計算と、印刷用 PDF・テスト印刷 PDF の作成（Node でも動く） |
| `design.js` | デザイン（背景・文字・画像・四角）の描画と、1枚もの PDF の作成 |
| `editor.js` | デザイン画面の操作（選択・移動・拡大縮小・元に戻す・保存） |
| `fonts.js` | フォントの読み込みと、文字を輪郭の線にする処理 |
| `labels.js` | PDF に入れる日本語の案内文字を画像にする |
| `preview.js` | 画面上のプレビュー |
| `app.js` | 全体のつなぎ（設定・原稿の読み込み・PDF の保存） |
| `fonts/` | フォントのデータと、各フォントのライセンス文（`fonts/licenses/`） |
